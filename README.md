# SAJHA YANTRA (साझा यन्त्र)

## Overview

SAJHA YANTRA is a frontend prototype for an agricultural service
marketplace platform designed for Nepal. The application connects
farmers, service providers, and machine operators through a
mobile-friendly interface.

## Features

-   Farmer Dashboard
-   Service Search
-   Agricultural Machinery Booking
-   Provider Management
-   Driver / Operator Management
-   GPS Fleet Tracking UI
-   AI-Based Recommendations
-   Booking Management
-   Multilingual Support (English & Nepali)
-   Mobile App Style User Interface

## User Roles

### Farmer

-   Search services
-   Book machinery
-   Track bookings
-   Receive AI suggestions

### Service Provider

-   Manage machines
-   Approve bookings
-   Monitor operations

### Operator

-   View assigned jobs
-   Navigate to farms
-   Update work status
